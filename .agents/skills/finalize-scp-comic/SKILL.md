# Finalize SCP comic from generated images

Use this when panel images have already been generated by imagegen or another external tool and the user wants to complete or update the comic.

This skill supports two modes:

- **Full finalize**: import all panel images for a new comic.
- **Single-panel replacement**: import one regenerated panel and recompose/re-embed using the existing accepted panels for the other panels.

## Inputs

Required:

- `id`: the SCP comic ID, e.g. `scp-173`.
- One image path for every panel that should be imported/replaced.

Full finalize example:

```text
panel 1: ./panel_1.png
panel 2: ./panel_2.png
panel 3: ./panel_3.png
panel 4: ./panel_4.png
```

Single-panel replacement example:

```text
panel 3: ./panel_3_retry.png
```

If image paths are missing, ask for them or locate obvious generated files under `output/<id>/panels_temp/`. Do not guess ambiguous files.

## Required reading

1. Read `AGENTS.md`.
2. Read the target script in `comics/queue/` or `comics/done/`.
3. Read `output/<id>/prompts/manifest.json` when present.
4. For single-panel replacement, inspect the current `output/<id>/panels/selected.json` when present so provenance is preserved/updated intentionally.

## Procedure

### 1. Resolve mode

- If the user supplies every panel image for a new comic, run full finalize.
- If the user supplies only `panel N`, run single-panel replacement. Import only that panel, then recompose using existing accepted panels for the other panels.

For single-panel replacement, verify that all other required accepted panels already exist before running `--skip-generate`. If they do not, ask for the missing images.

### 2. Validate script

Run validation:

```bash
python scripts/validate_scripts.py comics/queue/<id>.yaml
```

If the script is already in `comics/done/`, validate that path instead.

### 3. Import provided generated image(s)

For each provided panel image, run:

```bash
python scripts/accept_external_panel.py --id <id> --panel <N> --source <image-path> --provider imagegen
```

Use a more specific `--provider` label if the user requests it. Add `--note` for provenance when there is a useful review/regeneration reason, e.g. `--note "regenerated because previous panel contained pseudo-text"`.

`accept_external_panel.py` will:

- copy the raw input into `output/<id>/panels_temp/`;
- center-crop/resize to the configured accepted panel size, currently 720x720;
- save/replace `output/<id>/panels/panel_N.png`;
- update `output/<id>/panels/selected.json` with prompt/scene/provider/source dimensions/accepted dimensions.

Do not use `generated-page.png`, `base.png`, or any composed page as a panel source.

### 4. Compose and embed all languages

After every required accepted panel exists:

```bash
python scripts/run_pipeline.py --id <id> --skip-generate
```

Do not use `--languages` for the final publication run. A full-language run is required even when only one panel image was replaced, because the page and metadata must be regenerated consistently.

This creates/updates:

```text
output/<id>/base.png
output/<id>/thumbnail.png
output/<id>/ja.png
output/<id>/en.png
...
output/<id>/zh_Hant.png
output/<id>/meta.json
index.json
state/used.json
```

If the source script was in `comics/queue/` and the publish gate passes, the pipeline moves it to `comics/done/`.

### 5. Run explicit publish check

Run:

```bash
python scripts/publish_check.py <id>
```

Fix any reported errors before reporting completion.

### 6. Final visual review checklist

Inspect at least:

- the replaced panel inside `output/<id>/<lang>.png` when doing single-panel replacement;
- `output/<id>/thumbnail.png` if panel 1 was replaced;
- one language render such as `output/<id>/ja.png`;
- one non-Japanese render such as `output/<id>/en.png`;
- no text overflow warnings were reported;
- panel cropping looks acceptable after normalization.

## Completion report

Report:

- mode: full finalize or single-panel replacement;
- imported/replaced panel paths;
- generated output directory;
- whether the script moved to `comics/done/`;
- `publish_check.py` result;
- any visual/manual checks still needed.

## Git commit guidance

Commit production artifacts only when the user asks. Do not commit:

```text
output/<id>/panels_temp/
output/<id>/prompts/
output/<id>/generated-page.png
```
